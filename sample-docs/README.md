## 일부러 넣은 것

- 문서끼리 이어진 사실이 있습니다. 결제 코드의 지금 리뷰 규칙은 `02`에, 그 규칙을 바꾸게 만든 장애의 원인은 `06`에 있습니다. 한 문서만 찾아서는 답이 반쪽이 되는 질문을 만들 수 있습니다.
- 문서에 답이 없는 질문이 있습니다. 스테이징 주소와 휴가 신청은 일부러 적지 않았습니다. 서비스가 "모른다"고 답하는지 확인할 때 씁니다.
- 각 문서 맨 위에 제목, 담당자, 수정일이 들어 있습니다. 검색 결과에 출처를 붙일 때 씁니다.

## 형식

파일 이름은 터미널에서 다루기 쉽게 영문으로 지었고, 한글 제목은 메타데이터의 title에 있습니다. 모든 파일은 UTF-8 마크다운이고, 맨 위에 `---`로 감싼 메타데이터(title, team, owner, updated)가 있습니다.
